# <br>Usage
### **Open UI**
Is a (non-AI) code generator, for [Flutter](https://flutter.dev/) apps. It is available on all platforms...

&nbsp;&nbsp;&nbsp;[Android (Google Play)](https://play.google.com/store/apps/details?id=net.empathetech.open_ui)&nbsp;&nbsp;&nbsp;|&nbsp;&nbsp;&nbsp;[Android (.apk)](https://github.com/YWT-LLC/open_ui/releases/download/13.0.0/open-ui-android.apk)&nbsp;&nbsp;&nbsp;|&nbsp;&nbsp;&nbsp;[iOS](https://apps.apple.com/us/app/open-ui/id6499560244)&nbsp;&nbsp;&nbsp;|&nbsp;&nbsp;&nbsp;[Linux (deb)](https://github.com/YWT-LLC/open_ui/releases/download/13.0.0/open-ui-linux.deb)&nbsp;&nbsp;&nbsp;|&nbsp;&nbsp;&nbsp;[Linux (rpm)](https://github.com/YWT-LLC/open_ui/releases/download/13.0.0/open-ui-linux.rpm)&nbsp;&nbsp;&nbsp;|&nbsp;&nbsp;&nbsp;[macOS](https://github.com/YWT-LLC/open_ui/releases/download/13.0.0/open-ui-mac.zip)&nbsp;&nbsp;&nbsp;|&nbsp;&nbsp;&nbsp;[Windows](https://github.com/YWT-LLC/open_ui/releases/download/13.0.0/open-ui-windows.exe)

<br>Note: Mobile platforms simply save a configuration file that can be used on Desktop.<br>For code generation to work on Desktop, Flutter must be [installed](https://docs.flutter.dev/get-started/install).

### <br>Integrating Open UI with existing projects 

No longer has a formal guide. Since 11.1, Open UI enables live configuration. Every aspect of an app's theme can be updated on the fly, no restarts required. It's pretty darn efficient too.

However, there is a significant amount of setup/initialization code required to get it working.<br>Existing Open UI consumers have nothing to worry about: there's very little to do to get yourself 11.1+ ready.<br>However, the setup is no longer optional.

To accommodate the reduced wiggle room, 11.1 also reduced the number of external dependencies.<br>Open UI is as vanilla Flutter as possible. After you get your starter kit from Open UI, it should be happy hacking. Whether you're starting something new, or putting on some background noise and getting ready for a copy/paste session.
